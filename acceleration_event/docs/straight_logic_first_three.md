# 直线加速前三项逻辑修正

本轮以当前文件为准。当前文件已有固定 map 中心线存储、几何转换和规划质量接口，不能继续沿用此前关于局部历史存储、控制器独立配对的判断。

## 道路历史

规划器的 k/b 描述固定 map 中的 Y=kX+b。生成路径时按当前车辆位姿转换；短时保持仍使用原观测时间，不把重新发布当作新观测。回归覆盖车辆平移、偏航、重复帧与丢失观测。

## 道路方向保护

两组中心点间距达到 5.0-1.5=3.5 米才用于拟合方向；更近的两组仅更新位置。允许中间一组缺失后使用相距 10 米的两组，不强制恰好 5 米。

地图 X 轴来自车辆初始化朝向。首次可靠两组观测学习 track_reference_k；首次方向最大绝对斜率仍受 max_centerline_slope=0.25 约束，约 14 度。后续方向相对首次道路方向的角度变化上限为 atan(0.06)，约 3.43 度，不限制车辆本身偏航。首次学习前，不用地图 Y=0 两侧关系拒绝真实锥桶对，仍保留宽度及同排纵向距离约束。

只有一组时沿用已有方向；启动时只有一组仍采用 map 零斜率暂定方向，首次看到两组后更新。因此单组启动不能证明道路方向已确定。误配、传感器外参和初始方向质量仍须实测。

## 唯一控制参考

实际控制循环只跟踪 /planned_path 的前视点，取消直接中心线目标与过渡路径目标的混合。/planning/status 必须与路径时间戳匹配且观测有效；质量信息用于准入及记录，不再根据锥桶组数切换控制目标。旧局部投影辅助方法保留用于诊断兼容，实际控制循环不调用它们。

未修改速度、PD、转向编码、制动、终点判定、单边修正参数或组件版本。本轮不保证实车无摆动，执行器方向、滤波滞后、单边额外偏移和 VCU 失联行为仍待后续验证。
